# ADR 0001: Bing — локаль только через `setlang`, без `mkt` и `cc`

- **Дата:** 2026-10-07
- **Статус:** Accepted (решение владельца проекта)
- **Тема:** движок `bing` (`src/engine/engines/bing.rs`), отступление от эталона SearXNG

## Контекст

Движки проекта — порты движков SearXNG с теми же шаблонами URL (эталон).
При заданном языке поиска (например, `language` у MCP-инструмента `search`)
движок `bing` передавал `mkt=<язык>-<СТРАНА>`, и Bing из сети разработки почти
всегда отвечал HTTP 200 со страницей «There are no results for …»
(`ol#b_results > li.b_no`, ни одного `li.b_algo`). Клиент получал «no results»
без ошибки.

Актуальный `searx/engines/bing.py` (master, коммит 274b63b677 от 2026-09-13)
в веб-запросе не использует ни `mkt`, ни cookie: передаёт `setlang=<язык>` и
`cc=<страна>`, кроме `us`, `cn`, `ru` («bing just sends junk for these»).

Замеры (запрос `rust`, curl и живые вызовы через MCP, 2026-10-07):

| Параметры локали              | Результатов `b_algo`                |
|-------------------------------|-------------------------------------|
| нет                           | 10                                  |
| `setlang=en` / `ru` / `de` / `fr` | 10                              |
| `mkt=en-US`, `mkt=de-DE`      | 0 («no results»)                    |
| `cc=de` (без `setlang`)       | 0                                   |
| `setlang=de&cc=de`            | 0 через curl, 6 через MCP           |
| `setlang=fr&cc=fr`            | 0                                   |

Любой параметр страны/рынка (`mkt`, `cc`) нестабильно обнуляет выдачу;
`setlang` без страны давал результаты во всех замерах.

## Решение

Bing получает только `setlang=<основной язык>` (`de-DE` → `de`). Параметры
`mkt` и `cc` не передаются. Это отступление от эталона SearXNG в части `cc`.

## Альтернативы и обоснование

1. **`mkt` (прежнее поведение)** — отвергнуто: почти всегда пустая выдача.
2. **Точный порт SearXNG: `setlang` + `cc` (кроме us/cn/ru)** — отвергнуто:
   для de, fr и др. выдача нестабильно пустая; для en/ru совпадает с решением.
3. **Cookie `_EDGE_CD` / `_EDGE_S`** — в актуальном SearXNG не используются;
   не проверялись.
4. **`setlang` без страны (выбрано)** — стабильные результаты во всех замерах,
   минимальный набор параметров.

## Последствия

- **Плюсы:** bing отдаёт результаты при любом заданном языке; для en и ru
  запрос совпадает с SearXNG.
- **Минусы/риски:** Bing не учитывает страну (региональная выдача для de, fr,
  pt и т. п. может отличаться от SearXNG). Поведение Bing зависит от сети:
  если `cc` начнёт работать стабильно, решение стоит пересмотреть (вернуть
  `cc` по правилам SearXNG).
