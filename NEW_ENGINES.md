# NEW_ENGINES.md

Движки оригинального SearXNG, поиск которых **не связан с видео и аудио**,
и которые ещё **не портированы** в текущий проект searxng-rs.

Уже реализованные движки (`google`, `bing`, `duckduckgo`, `wikipedia`,
`brave`, `yandex`, `yahoo`, `baidu`, `naver`, `startpage`, `google_news`,
`bing_news`, `google_images`, `bing_images`, `github`, `gitlab`, `npm`,
`pypi`, `docker_hub`, `crates`, `hackernews`) из списка исключены.
